# QuinSland - Branding Guide

## Brand Overview

**App Name:** QuinSland  
**Tagline:** "Play. Compete. Earn."  
**Category:** Gaming/Multiplayer Games  
**Target Audience:** Ages 13-35, Gamers worldwide

---

## 🎨 Logo Specifications

### Primary Logo
```
QuinSland
Q◆S (Gaming emblem)
```

**Logo Colors:**
- Primary: Electric Purple (#7C3AED)
- Secondary: Vibrant Cyan (#00D9FF)
- Accent: Neon Orange (#FF6B00)
- Dark Background: (#0F0F0F)

### Logo Variations
1. **Full Logo** - Text + Icon (App stores, website headers)
2. **Icon Only** - Q◆S emblem (App icon, favicon)
3. **Horizontal** - Logo + text side-by-side
4. **Vertical** - Icon stacked above text
5. **Monochrome** - Black/white versions

### Logo Files Needed
- `logo-primary.png` (3000x3000px)
- `logo-icon.png` (1024x1024px - for app stores)
- `logo-horizontal.png` (1500x500px)
- `logo-favicon.ico` (256x256px)

## 📱 App Icon Design

### iOS App Icon
- Size: 1024x1024px
- No rounded corners (OS handles this)
- Safe zone: 900x900px minimum

### Android App Icon
- Size: 512x512px
- Rounded corners: 108dp
- Safe zone: 432x432px minimum

### App Icon Specifications
```
Primary: Q◆S emblem
Background: Gradient (Purple to Cyan)
Style: Flat design with depth
Border: Subtle glow effect
```

## 📊 Brand Voice & Tone

### Voice Characteristics
- **Energetic** - Exciting, dynamic language
- **Inclusive** - Welcoming to all skill levels
- **Competitive** - Motivating players to compete
- **Fun** - Playful, not serious

### Tone Examples

❌ **Don't:** "Click here to proceed to authentication"  
✅ **Do:** "Jump into the game!"

❌ **Don't:** "You lost the match"  
✅ **Do:** "Nice try! Ready for round 2?"

❌ **Don't:** "Earn money through referrals"  
✅ **Do:** "Earn cash by spreading the fun!"

## 📸 Imagery Guidelines

### Game Screenshots
- Show gameplay in action
- Include UI elements
- Highlight multiplayer moments
- Use landscape orientation (16:9)

### User Photos
- Diverse representation
- Authentic moments
- Celebration/excitement expressions
- High quality (minimum 1920x1080)

### Prohibited
- Blurry images
- Stock photos that look fake
- Violence or inappropriate content
- Competitor branding

---

## 🎬 Video Assets

### Trailer Video (30-60 seconds)
- Hook: 0-3 seconds (Show exciting gameplay)
- Features: 3-20 seconds (Highlight main features)
- Call-to-action: 20+ seconds (Download now!)
- Format: 16:9, 1080p minimum

### TikTok/Shorts Format (9-15 seconds)
- Vertical video (9:16)
- Fast-paced editing
- Text overlays
- Trending music
- High retention (aim for 100%+ replay rate)

### YouTube Thumbnail
- Size: 1280x720px
- High contrast colors
- Large text (readable at small sizes)
- Emotional expression if using faces
- Brand colors included
