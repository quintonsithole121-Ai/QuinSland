# QuinSland Gaming Platform

A modern online gaming platform built with React, Node.js, and MongoDB.

## Features

- 🎮 Multiplayer gaming capabilities
- 👥 User authentication and profiles
- 🏆 Leaderboards and achievements
- 💬 Real-time chat and matchmaking
- 📊 Game statistics and analytics
- 🎨 Responsive UI design

## Tech Stack

- **Frontend**: React, Vite, Tailwind CSS
- **Backend**: Node.js, Express.js
- **Database**: MongoDB
- **Real-time**: Socket.IO
- **Authentication**: JWT

## Project Structure

```
QuinSland/
├── frontend/          # React application
├── backend/           # Node.js server
├── docs/             # Documentation
└── package.json      # Project metadata
```

## Getting Started

### Prerequisites

- Node.js (v16+)
- npm or yarn
- MongoDB

### Installation

```bash
# Clone the repository
git clone https://github.com/quintonsithole121-Ai/QuinSland.git
cd QuinSland

# Install dependencies
npm install

# Setup environment variables
cp .env.example .env

# Start development server
npm run dev
```
